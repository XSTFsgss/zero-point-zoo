# 安月 AN YUE · 原创 IP 角色交互手机 APP

一款以原创 IP 角色「**安月（An Yue）**」为核心的移动交互应用原型，结合角色陪伴、日常互动、手绘探索日记与异常警报叙事，适用于原创角色 IP 设计课程毕业作品与交互展示。

## 功能模块

1. **首页 HOME**：展示安月完整角色立绘、4 种可切换星夜探索场景（星夜观测营、荧光迷雾林、旧天文台迹、晨曦观察哨）、今日心情与日常对话气泡、以及直接点击角色部位的即时反馈。
2. **角色档案 CHARACTER**：卡片化展示角色身份、经典台词、四大性格关键词（细腻、谨慎、敏感、勇敢）、5 种表情形态切换展示区、专属物品档案（黄色对讲机、螺旋观察笔记本、探险风装备组）与背景故事。
3. **探索日记 DIARY**：手绘线圈笔记本风格，支持添加日期、分类、文字、上传照片或手绘草图贴纸；每篇日记自动触发安月的上下文对话回应，并可生成专属「探索记录卡（EXP-XXX）」，数据持久化保存于 `localStorage`。
4. **异常警报 ALERT**：点击「发现异常」进入警戒状态，安月切换至举起黄色对讲机的警戒立绘，支持 3 档警报状态（待机巡查 / 一级预警 / 警戒呼叫）、3 组异常线索案例与同伴无线电播报，并可一键将异常线索归档进探索日记。
5. **角色互动 INTERACTION**：支持显示/隐藏互动热区，点击左耳、右耳、头部、黄色对讲机、观察笔记本触发对应表情（害羞、惊讶、开心、警戒）、动画与 Web Audio 合成音效，并提供早/午/夜问候、随机日常对话与探索默契度。

## 本地运行

```bash
cd /Users/liangluyu/.gemini/antigravity/scratch/anyue-ip-app
ruby -run -e httpd . -p 4173
```

然后在浏览器或手机端访问 `http://127.0.0.1:4173`。
